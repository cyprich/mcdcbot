# mcdcbot

Minecraft - Discord bot

It was supposed be a Discord bot, which allows to read some stats from Postgres database, where I store some stuff for Minecraft
So it's not directly connected to my Minecraft Server  

Right now, it's only used for CRUD operations over waypoints  
In the future, I would like to

- Add ability to generate reports using my [`minecraft-wrapped` project](https://github.com/cyprich/minecraft-wrapped)
- Integrate it with the actual Minecraft Server  

...but let's these are just future plans
